# AI API Testing & Quality Assurance Agent

An AI-powered API quality assurance system that automatically analyzes APIs, generates test cases, executes tests, detects failures, and produces QA reports.

## Features

- API specification analysis
- Swagger / OpenAPI documentation
- AI-generated test cases
- Functional testing
- Negative testing
- Automated API test execution
- AI-based result analysis
- LangGraph agent workflow
- RAG-based knowledge retrieval
- ChromaDB vector database
- PostgreSQL database
- Redis caching
- QA report generation
- Web dashboard

## Technologies

- Python
- FastAPI
- REST API
- Swagger / OpenAPI
- Groq LLM
- LangGraph
- RAG
- ChromaDB
- PostgreSQL
- Redis
- Postman
- Git & GitHub
